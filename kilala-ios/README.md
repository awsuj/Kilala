# Kilala iOS Client

This folder contains the native iOS application built with Swift and SwiftUI for Cardholders and Businesses.

## Setup Instructions
1. Open Xcode.
2. Select **Create a new Xcode project**.
3. Choose **iOS > App**, name the product **Kilala**, select **SwiftUI** for the Interface, and **Swift** for the Language.
4. Save the project directly inside this `kilala-ios/` directory.
